# Security policy

AuthOwl is an authentication product developed and maintained by Devcoat.
Security reports for AuthOwl SDKs are handled by the Devcoat security team.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[contact@devcoat.com](mailto:contact@devcoat.com). Do not open a public GitHub
issue for an unpatched security problem.

Include the following when available:

- The affected package, version, platform, and configuration.
- Reproduction steps or a minimal proof of concept.
- The security impact you observed.
- Any suggested mitigation or remediation.
- A safe way to contact you for follow-up.

We will acknowledge the report, investigate it, and coordinate remediation and
disclosure with the reporter. Please allow a reasonable remediation period
before publishing details.

## Scope

This repository covers the official AuthOwl client and server SDK packages.
Reports concerning the hosted AuthOwl service, dashboard, or infrastructure
should use the same private contact address.

Security questions, feature requests, and general support requests are not
vulnerability reports and may be redirected to the appropriate support path.
