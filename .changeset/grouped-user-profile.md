Group UserProfile into Profile, Security, Connected accounts and Privacy with compact summary rows, an identity sidebar, container-responsive navigation and an SDK-owned phone modal sheet. Add English and Modern Standard Arabic group subtitles and action labels, and regenerate the Dart catalog.

Included in the unreleased React major. DOM-contract changes for the migration guide: per-section navigation buttons become group anchors with aria-current="page"; group content contains every available section in order; Edit/Manage opens each existing form inline. Closing a row unmounts its workflow. Section hashes and section props keep their existing identifiers, with deep links focusing the requested heading. New profile row, identity, group-heading and sheet-handle appearance slots emit both ao- and ba- classes. The modal uses a 92dvh bottom sheet only at viewport widths of 480px or less; navigation changes at a 640px container width. See docs/react-appearance-migration.md for the complete contract.

Review fixes: initial section/defaultSection/hash requests open the requested row; nav clicks and later controlled changes land collapsed, with heading focus after controlled changes. Each disclosure h2 is its row title; Sessions and Social retain list headings, and modal group titles are h2. Page mode removes its global h1/description. The danger-zone wrapper is removed, and session/social row actions use profile-row-button. PrivacyCenter mounts only on opening its row. Closing uses common.close, cancels parked actions and invalidates late step-up verification. The phone sheet breakpoint changes from 680px to 480px, with contained overscroll and no bottom border. Shared Avatar uppercases the first grapheme, falls back to the first code point when segmentation is unavailable, sends no image referrer, falls back after image failure, and omits absent email lines. Deprecated catalog keys remain available for override compatibility through 1.0, until a later major. See the migration guide for the updated slots and DOM contract.
